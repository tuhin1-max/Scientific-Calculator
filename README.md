# Tuhin Scientific Calculator

A fully functional GUI-based Scientific Calculator built using **Python** and **Tkinter**. This application provides an interactive desktop interface to perform both standard arithmetic operations and essential scientific calculations.

## 🚀 Features
- **Graphical User Interface (GUI):** Clean and responsive layout using Tkinter widgets.
- **Basic Arithmetic:** Supports addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
- **Scientific Functions:** 
  - Trigonometric operations: `sin`, `cos`, `tan` (automatically converts degrees to radians).
  - Logarithmic calculations: `log` (base 10).
  - Advanced math: Square root (`√`) and exponents (`^`).
- **Error Handling:** Built-in error trapping that displays an "Error" message instead of crashing on invalid expressions (e.g., division by zero).

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **GUI Framework:** Tkinter
- **Math Library:** Python's built-in `math` module

## 💻 How to Run Locally

### Prerequisites
Make sure you have Python installed on your system. You can download it from [python.org](https://www.python.org/).

### Steps
1. Clone this repository:
```bash
   git clone [https://github.com/tuhin1-max/Scientific-Calculator.git](https://github.com/tuhin1-max/Scientific-Calculator.git)
   ```
2. Navigate into the project directory:
```bash
   cd Scientific-Calculator
   ```
3. Run the Python application:
```bash
   python calculator.py
   ```
   *(Note: Rename your python file to `calculator.py` or use your current filename instead)*
